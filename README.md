# Daily Stock View

Daily Stock View is a personal A-share strategy brief and research archive project.

The first product direction is a mobile-first, long-term saved, broker morning-brief style system for generating and reviewing daily market strategy notes. It is intended for research support and decision hygiene, not as an automated trading or direct stock recommendation tool.

## MVP Direction

- Daily morning strategy brief
- Historical strategy archive
- Medium-term theme files
- Stock and ETF watchlist
- Daily and weekly review workflow
- AI-assisted draft generation with human confirmation

## Disclaimer

This project is for research, journaling, and information organization. It does not provide personalized investment advice, guaranteed returns, or automated trading instructions.
