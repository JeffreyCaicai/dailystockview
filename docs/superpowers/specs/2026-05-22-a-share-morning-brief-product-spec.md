# A 股智能策略内参系统产品规格

日期：2026-05-22  
版本：MVP v0.1  
定位：手机优先、长期保存、券商晨会纪要风格的个人投研内参系统  
声明：系统输出用于研究参考，不提供收益承诺，不替代用户独立判断，不以“买入/卖出”作为核心交互语言。

## 1. 产品目标

建立一个在线系统，帮助用户每天用手机阅读、生成、保存和复盘 A 股策略内参。系统第一版不追求全自动行情抓取，而是先验证“结构化内参 + 主线沉淀 + 股票观察池 + 复盘”的核心闭环。

用户每天希望解决的问题：

- 今天市场处于什么状态？
- 中期主线是否仍然成立？
- 哪些行业值得继续跟踪？
- 哪些股票只是观察，不应冲动交易？
- 哪些风险信号说明需要降低仓位或暂停进攻？
- 昨天/上周的判断是否被市场验证？

## 2. 产品风格

第一版采用“券商晨会纪要”风格：

- 信息密度较高，但手机阅读要清晰。
- 结构稳定，每天都按同一框架生成。
- 语言专业、克制，不使用夸张荐股话术。
- 强调市场状态、行业主线、验证指标、风险提示。
- 弱化盘中短线异动，不做高频交易看板。

参考内容形态：

- 券商晨会摘要。
- 买方投研早会纪要。
- 私人策略内参。
- 股票观察池更新说明。

## 3. 第一版 MVP 范围

### 3.1 必须包含

1. **每日晨会内参**
   - 用户输入行情、新闻、截图转写、研报摘要或手工笔记。
   - AI 生成统一格式的晨会内参。
   - 内参可保存、回看、编辑。

2. **历史内参**
   - 按日期浏览过去的每日内参。
   - 支持查看市场基调、主线排序、风险提示、验证点。

3. **主线档案**
   - 保存中期主题，例如半导体、AI 算力、机器人、电力储能、高股息等。
   - 每条主线记录阶段、逻辑、代表标的、证伪条件、跟踪指标。

4. **股票观察池**
   - 保存股票和 ETF，不称为“买入池”。
   - 每个标的绑定所属主线、观察原因、状态、验证点、风险点。

5. **复盘**
   - 支持每日或每周复盘。
   - 记录市场是否验证此前判断、主线变化、个人纪律执行情况。

### 3.2 第一版暂不做

- 实时行情。
- 自动交易。
- 盘口/分钟级短线提醒。
- 多用户订阅和支付。
- 完整券商级行情数据库。
- 自动抓取全网新闻。
- 个性化直接买卖建议。

这些能力可以放到后续版本。

## 4. 信息架构

第一版包含 5 个主页面：

1. 首页：今日晨会内参
2. 历史内参
3. 主线档案
4. 观察池
5. 复盘

移动端底部导航建议：

- 今日
- 历史
- 主线
- 观察
- 复盘

桌面端可以使用左侧导航。

## 5. 页面规格

### 5.1 首页：今日晨会内参

首页展示当天最新内参。若当天未生成，显示输入入口。

页面区块：

1. **顶部状态栏**
   - 日期
   - 市场基调：进攻 / 轮动 / 防守 / 高波动
   - 风格判断：成长 / 价值 / 红利 / 周期 / 混合
   - 仓位倾向：积极 / 中性 / 谨慎

2. **一句话总观点**
   - 例如：市场仍处高成交结构行情，但科技主线进入高位分歧，宜等待龙头承接和低位成长扩散验证。

3. **今日摘要**
   - 3-5 条短要点。
   - 每条控制在一屏内可扫读。

4. **市场回顾**
   - 指数表现。
   - 成交额变化。
   - 涨跌家数。
   - 强弱板块。
   - 外围影响。

5. **策略观点**
   - 当前市场阶段。
   - 中期主线判断。
   - 短线过热方向。
   - 需要降风险的信号。

6. **行业晨会纪要**
   - 每个行业以折叠卡片展示。
   - 默认展示前 3 个优先级最高行业。
   - 每个行业字段：核心逻辑、最新催化、验证指标、风险点、代表标的。

7. **股票观察池更新**
   - 新增观察。
   - 继续观察。
   - 降低关注。
   - 暂停观察。

8. **风险提示**
   - 今日不宜追高方向。
   - 可能退潮主线。
   - 宏观/政策/外围扰动。
   - 个股层面风险。

9. **本周验证点**
   - 3-7 条，用于后续复盘。

### 5.2 历史内参

用途：形成长期投研记忆。

功能：

- 按日期倒序展示内参列表。
- 列表显示：日期、市场基调、风格判断、最强主线、风险等级。
- 支持打开详情。
- 支持按主线、股票、市场基调筛选。

MVP 可先做：

- 日期列表。
- 详情查看。
- 简单搜索。

### 5.3 主线档案

用途：防止用户每天被短期热点带着跑。

每条主线字段：

- 主线名称。
- 当前阶段：启动 / 加速 / 分歧 / 兑现 / 退潮。
- 优先级：高 / 中 / 低。
- 核心逻辑。
- 政策逻辑。
- 产业逻辑。
- 业绩验证点。
- 资金观察点。
- 代表标的。
- ETF 或替代工具。
- 证伪条件。
- 最新更新日期。
- 历史更新记录。

示例主线：

- 半导体。
- AI 算力。
- 机器人。
- 电力/储能。
- 高股息/资源。
- 消费复苏。
- 医药创新。

### 5.4 股票观察池

用途：跟踪标的逻辑变化，而不是发出交易指令。

股票状态：

- 关注。
- 等待确认。
- 降低关注。
- 暂停观察。
- 逻辑证伪。

股票分组：

- 核心龙头。
- 景气验证。
- 低位修复。
- ETF 工具。
- 暂停观察。

每个标的字段：

- 代码。
- 名称。
- 市场：A 股 / 港股 / 美股 / ETF。
- 所属主线。
- 分组。
- 当前状态。
- 加入观察池原因。
- 公司逻辑。
- 未来验证点。
- 估值风险。
- 技术位置概览。
- 证伪条件。
- 最近一次观点变化。
- 创建日期。
- 更新日期。

界面要求：

- 手机端使用卡片列表。
- 卡片第一屏只展示名称、状态、所属主线、核心逻辑摘要。
- 详情页展示完整分析。
- 状态变化要记录历史，便于复盘。

### 5.5 复盘

用途：让系统形成闭环，而不是每天生成新故事。

复盘类型：

- 日复盘。
- 周复盘。

复盘字段：

- 日期或周期。
- 上次市场判断是否验证。
- 被验证的主线。
- 被证伪的主线。
- 新出现的风险。
- 观察池变化。
- 用户个人纪律记录。
- 下个交易日/下周验证点。

个人纪律记录建议选项：

- 是否追高。
- 是否重仓单一主题。
- 是否按计划等待确认。
- 是否因为情绪改变原计划。
- 是否执行降仓条件。

## 6. AI 生成流程

### 6.1 用户输入

用户每天可以输入：

- 指数和成交数据。
- 板块涨跌。
- 新闻摘要。
- 券商研报摘要。
- 朋友发来的截图文字。
- 自己的观察笔记。

第一版可以使用一个大文本框，支持粘贴混合内容。

### 6.2 AI 输出

AI 生成以下结构：

1. 今日摘要。
2. 市场回顾。
3. 策略观点。
4. 行业晨会纪要。
5. 股票观察池更新建议。
6. 风险提示。
7. 本周验证点。
8. 需要人工确认的数据缺口。

### 6.3 人工确认

AI 生成后，不直接入库为最终版本。用户需要：

- 查看。
- 编辑。
- 确认保存。

保存后，系统自动更新：

- 当日内参。
- 相关主线档案更新记录。
- 股票观察池状态变化。
- 后续复盘待验证项。

## 8. 第一版交互流程

### 8.1 生成每日内参

1. 用户打开首页。
2. 如果今天没有内参，点击“生成今日内参”。
3. 粘贴行情、新闻、研报、截图文字、个人笔记。
4. 点击“生成”。
5. AI 输出结构化晨会内参。
6. 用户编辑确认。
7. 点击“保存为今日内参”。
8. 系统保存并提示是否同步更新主线和观察池。

### 8.2 查看历史内参

1. 用户进入历史页。
2. 按日期浏览。
3. 点击某日内参。
4. 查看当天观点、主线、风险、验证点。

### 8.3 更新股票观察池

1. 用户进入观察池。
2. 新增股票或 ETF。
3. 填写所属主线和观察原因。
4. AI 可辅助补全公司逻辑、验证点、风险点。
5. 用户确认保存。

### 8.4 做周复盘

1. 用户进入复盘页。
2. 选择“生成本周复盘”。
3. 系统读取本周内参、主线变化、观察池变化。
4. AI 生成复盘草稿。
5. 用户补充个人纪律记录。
6. 保存复盘。

## 9. 内容语气规范

系统输出应使用以下表达：

- 关注。
- 等待确认。
- 降低关注。
- 暂停观察。
- 逻辑待验证。
- 逻辑增强。
- 逻辑证伪。

避免使用：

- 必买。
- 梭哈。
- 稳赚。
- 保底收益。
- 明天必涨。
- 无脑买入。
- 目标翻倍。

所有重点标的必须包含：

- 核心逻辑。
- 验证指标。
- 风险点。
- 证伪条件。

## 10. 成功标准

第一版成功不以收益率衡量，而以流程质量衡量：

- 用户每天能在 3-5 分钟内读完核心内参。
- 用户能清楚知道今日市场基调和中期主线。
- 每条主线都有可追踪的验证点。
- 股票观察池状态变化有记录。
- 每周至少能完成一次复盘。
- 系统能帮助用户减少冲动交易和信息焦虑。

## 11. 后续版本路线

### v0.2 半自动数据版

- 支持 CSV/Excel 导入行情和自选股。
- 支持自动计算板块评分和股票观察分。
- 支持更丰富的历史筛选。

### v0.3 自动资讯版

- 接入公开新闻源。
- 自动提取政策、公告、研报要点。
- 生成数据缺口提醒。

### v0.4 行情增强版

- 接入行情 API。
- 自动更新指数、成交额、板块涨跌、个股表现。
- 支持主线热度趋势图。

### v0.5 多端与提醒版

- 移动端 PWA。
- 邮件或推送提醒。
- 每周复盘自动提醒。

### v1.0 个人投研知识库

- 支持长期主线图谱。
- 支持股票逻辑演变时间线。
- 支持个人投资纪律评分。
- 支持多市场：A 股、港股、美股。

## 12. 设计决策

已确认：

- 产品形态：在线系统，手机可访问，长期保存。
- 第一版风格：券商晨会纪要。
- 用户风格：偏中线/波段，不以短线交易为主。
- 第一版核心：每日内参、历史内参、主线档案、观察池、复盘。
- AI 流程：先手动输入资料，AI 生成草稿，用户确认保存。

暂不确定，后续再定：

- 具体技术栈。
- 是否先做登录。
- 云服务选择。
- 是否做 PWA。
- 行情数据 API 来源。
- AI 模型与调用方式。

## 13. 下一步建议

下一步进入实现规划前，需要确认：

1. 第一版是否需要账号登录，还是先做单用户私有系统。
2. 是否优先适配手机浏览器。
3. 是否希望第一版就接 OpenAI API 生成内参。
4. 是否需要导入历史研报和已有观察池。

我的建议是：

- 单用户私有系统。
- 手机优先。
- 第一版接 AI 生成。
- 暂不导入大量历史数据，先从上线当天开始积累。
